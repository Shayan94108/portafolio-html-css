Información del sitio

Aviso legal

Este sitio es un trabajo académico de Jhojan Sebastian Alipour Rivera para practicar HTML5 y CSS3. Los proyectos del portafolio son ejercicios de aprendizaje. No se presentan como encargos profesionales de clientes reales.

Los datos de contacto, la dirección y la ubicación del mapa son ficticios. La página no ofrece contratación ni gestiona solicitudes comerciales. Los nombres y contenidos de ejemplo se utilizan para mostrar la estructura y el diseño de una web.

Los enlaces a Instagram y LinkedIn dirigen a las páginas generales de esas plataformas. El enlace de GitHub conduce al perfil público indicado en el proyecto.

Uso del formulario de prueba

Política de privacidad

El formulario de presupuesto es una demostración académica de validación HTML5. Utiliza únicamente datos ficticios al probarlo. Los campos obligatorios y el checkbox de aceptación permiten comprobar la validación del navegador.

Al continuar, los valores de prueba se añaden a la dirección de la página. No se envía ningún correo ni existe un servicio de gestión de presupuestos o una base de datos propia de este proyecto.

El alojamiento y las plataformas externas pueden tratar información técnica de las visitas conforme a sus propias políticas. Estos textos describen esta demostración y no constituyen una política preparada para una actividad comercial real.
