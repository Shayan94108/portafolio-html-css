# Mi portafolio web

Trabajo final de HTML/CSS de Jhojan Sebastian Alipour Rivera.

## Enlaces para la entrega

- Repositorio: https://github.com/Shayan94108/portafolio-html-css
- GitHub Pages: https://shayan94108.github.io/portafolio-html-css/

## Archivos

- index.html: presentación, sobre mí, qué estoy aprendiendo y ejercicios.
- portfolio.html: galería con cuatro imágenes de ejercicios básicos.
- presupuesto.html: formulario de presupuesto de prueba.
- contacto.html: datos ficticios, mapa, aviso legal y privacidad.
- css/estilos.css: estilos de todas las páginas.
- img/: imágenes de ejercicios, mapa y logotipos de redes sociales.

He utilizado HTML5 y CSS3. El diseño tiene un contenedor centrado, un menú superior y una galería con dos columnas. En el móvil la galería pasa a una columna. No se utiliza JavaScript.

## Cómo probarlo

Abrir index.html o entrar en la dirección de GitHub Pages. Desde el menú se puede navegar por las cuatro páginas.

El formulario tiene todos los campos obligatorios. El email debe tener formato de correo, el teléfono debe tener nueve números y hay que aceptar la política de privacidad. Es una demostración: usa datos ficticios y no envía correos. Al continuar, los valores de prueba aparecen en la dirección de la página.

Los datos de contacto y el mapa son ficticios. Las imágenes de la galería son ejemplos visuales de ejercicios, no trabajos de clientes.

## Para hacer cambios

Los textos están en los archivos HTML. Los colores, tamaños y márgenes se pueden cambiar en css/estilos.css. Si se cambia el menú o el pie, hay que hacerlo en las cuatro páginas.

El archivo para entregar se llama jhojan_alipour_trabajoHTML.zip. Este README contiene los dos enlaces que pide el campus.
